# Sweetie — статическая копия сайта

Этот проект содержит HTML-копию сайта Sweetie и локальные ресурсы для публикации через GitHub Pages.

## Публикация
1. Создайте публичный репозиторий `sweetie-decor` на GitHub.
2. Распакуйте ZIP и загрузите `index.html` и папку `assets` в корень репозитория (не загружайте ZIP вместо файлов).
3. Settings → Pages → Build and deployment → Deploy from a branch.
4. Выберите `main` и `/(root)`, сохраните.
5. Откройте https://USERNAME.github.io/sweetie-decor/ (USERNAME замените на свой логин).

## Перед публикацией
- Проверьте права на дизайн, фотографии, логотип и контент.
- Проверьте изображения, мобильное меню, внешние ссылки, видео и форму.
- Скопированная форма Tilda может не отправлять заявки с GitHub Pages; подключите отдельный обработчик.
- В портфолио честно обозначайте свою роль (например, редизайн/верстка, если это ваша работа), не выдавая копию чужого сайта за авторскую разработку.
